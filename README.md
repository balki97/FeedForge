# FeedForge

![FeedForge icon](assets/feedforge.png)

FeedForge is a Windows companion app for FeedBack packages.

## Download

Download the portable EXE from the latest GitHub release:

https://github.com/balki97/FeedForge/releases/latest

## Links

- Website: https://feedforge.org
- Discord: https://discord.gg/9cUe6cacQN

For bug reports, include:

