# FeedForge 2.0.0

Songsterr creation and the PSARC convertor are now in one application, alongside
the FeedPak library, editor, and stem tools.

- Create FeedPaks from Songsterr links, with guitar, bass, and drum arrangements.
  Edit release details, artwork, track roles, and synchronized lyrics; import LRC
  files or use local audio. Multiple links can be processed as a batch.
- Choose whether to include stems before starting a conversion. FeedForge checks
  the server and takes you to the appropriate setup screen when needed.
- Use the same stem model and instrument selection for PSARC and Songsterr songs.
- A simpler Home page, consistent dark controls, clearer forms, the FeedForge
  logo, and service-colored sidebar links.
- Library folders open directly in Library & editor, including folders already
  loaded in the session. PSARC conversion leaves library packages untouched.
- Safer package editing, clearer conversion warnings, and fixes for drum counts
  and transcriber credits.

Windows: portable EXE. macOS: Apple Silicon DMG or ZIP. Linux: x64 AppImage.
Local stem splitting requires Python 3.11 or newer; FeedForge installs the
remaining dependencies from Tools · stems. Online artwork, lyrics, and video
downloads depend on their providers; local audio remains available.
